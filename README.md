# graphlib

Graphib is a simple graphics library built over SDL2. 

It's end goal is to be used to make an animation program, but this animation program will probably not be made in the near future.

Features to implement **NOT IN ORDER**:

1. Widgets
2. Circle drawing

Main.c shows an example, though it relies on sdl scancodes for key input at the moment.


The library is split up into different files for readibility and ease of development.

They are listed in the GLIB folder.
